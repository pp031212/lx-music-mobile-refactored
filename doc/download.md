# 安卓歌曲下载

在线歌曲菜单中选择「下载」，再选择音质；多选歌曲后可一次创建多个任务。
主导航的「下载管理」页面提供进度、开始全部、暂停全部、单项重试、移除记录和删除文件。
主设置界面新增「下载设置」分组，横竖屏均可访问；下载管理页也保留同一组设置的快捷入口，
两处共用组件和设置数据，修改立即同步。

## 与桌面版下载设置的对应关系

| 桌面版选项 | 安卓版当前行为 |
| --- | --- |
| 保存目录 | 支持应用内目录和授权的外部目录 |
| 同时下载数 | 支持 1～3 首；桌面版提供 1～6 首 |
| 自动换源 | 支持同音质换源，默认关闭 |
| 文件命名格式 | 支持歌名－歌手、歌手－歌名、歌名；附加音质与任务标识防止覆盖 |
| 数据嵌入 | 歌曲标签和原文歌词共用一个开关 |
| 独立歌词 | 支持保存原文 `.lrc`，使用 UTF-8 |
| 下载功能总开关 | 暂无独立总开关，在线歌曲菜单直接提供下载入口 |
| 跳过已有文件 | 跳过相同歌曲与音质的已有任务；尚未按外部文件扫描去重 |
| 按歌单建立目录 | 尚未实现 |
| 封面嵌入、翻译/罗马音/逐字歌词及 GBK | 尚未提供对应设置 |

## 行为

- 参考桌面版的任务流程：排队、按音质获取地址、下载、保存文件、标记完成。
- 音质需同时被歌曲信息和当前自定义源支持。重复的歌曲与音质不会创建第二个任务。
- 默认并行下载两首，可设置为一至三首。失败后刷新地址重试一次，仍失败则等待手动重试。
- 暂停会停止网络传输。对于具有强 ETag 和已知文件大小的音频，Android 会保留已下载的片段，重启后仍可继续。
- 继续下载时使用 HTTP Range。只有地址、ETag、总大小和起始偏移均匹配时才追加；音源忽略 Range、地址变化或文件无法验证时，会从头下载。
- 文件先写入应用内临时目录，检查 HTTP 状态、响应类型、大小后复制到目标目录。
  复制成功且大小匹配后才标记完成。歌词或标签失败不影响已保存音频，会显示提示。
- 可选择同音质自动换源，默认关闭；不自动降低所选音质。
- 文件名包含音质和任务标识，避免覆盖同名歌曲或其他音质。
- 完成的歌曲从下载列表直接播放本地文件。文件丢失时显示错误，不悄悄切回在线播放。
- 未完成任务在下次启动时恢复为暂停，不自动占用网络。删除任务时一并清理该任务的临时文件。
- 「仅移除记录」保留歌曲及歌词；「同时删除文件」删除该任务保存的音频和独立歌词。

## 存储与后台

默认保存到应用内 `downloads` 目录，无需额外存储权限。卸载应用会删除此目录。
可在下载设置中使用已有目录选择器授权并选择外部目录；目录设置对下一次开始的任务生效。
已经保存的歌曲不会因修改目录而移动。

应用退到后台时保存任务记录。网络传输由现有原生文件库执行，但本实现没有增加 Android
前台下载服务，长期息屏、系统清理进程后的连续下载不作保证。手动退出时暂停并保存任务。

## 结构

- `src/core/download/manager.ts`：与平台无关的任务队列、取消隔离、状态恢复和串行持久化。
- `src/core/download/index.ts`：自定义源、原生文件传输、目录保存及歌词/标签适配。
- `src/components/DownloadModal.tsx`：单曲/批量音质选择。
- `src/screens/Home/Views/Download/index.tsx`：任务列表和下载设置。
- `src/screens/Home/Views/Setting/settings/Download/index.tsx`：主设置分组及共用的下载设置控件。
- `src/core/music/download.ts`：已下载歌曲的本地播放和歌词读取。

## 验证

```sh
npm run test:download
```

使用项目 TypeScript 编译独立队列模块，在 Node 内测试并发、取消、迟到回调、失败重试、
文件不完整、发布失败、任务删除、记录恢复和持久化顺序，不需要启动 React Native。

真机验收：

1. 导入可用自定义源，分别从搜索和我的列表中下载单曲、多选歌曲；核对音质及重复任务跳过。
2. 检查多个任务排队、进度和并发上限；下载期间暂停、重试、删除，确认任务不再被迟到回调改回运行。
3. 选择授权的外部目录，确认音频和 `.lrc` 可从文件管理器打开；撤销目录权限后确认任务显示失败。
4. 下载完成后断网，播放下载列表、上一首/下一首，重启后恢复播放；删除文件后确认显示文件丢失。
5. 分别测试仅移除记录和同时删除文件；确认其余歌曲不受影响。
6. 下载时手动退出、强制结束进程，再启动确认未完成任务暂停、已完成记录仍能播放。
